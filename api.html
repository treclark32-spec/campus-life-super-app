How Our App Uses APIs

Open-Meteo Weather API

Our application uses the Open-Meteo API to retrieve current weather information for LaGrange, Georgia.

  • Current temperature
  • Weather conditions
  • Wind speed
  • Humidity

Why APIs Matter

APIs allow different applications to communicate and share information. They help websites retrieve updated information without manually entering every piece of data.

  • Retrieve outside information
  • Display updated data
  • Improve website functionality
  • Connect different services

About This Project

The Campus Life Super App is designed to help LaGrange College students stay connected with campus activities and useful information.

This project combines HTML, CSS, Bootstrap, JavaScript, and API integration.
